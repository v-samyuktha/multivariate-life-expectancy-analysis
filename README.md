# Multivariate Life Expectancy Analysis

Team project for **Regression and Multivariate Analysis** Course at IIT Hyderabad.

Analysed life expectancy data from 2010–2015 to investigate relationships between life expectancy and health, demographic and economic indicators.

**Authors:** Samyuktha V, Gowri Govindaraj

**Dataset:** [Life Expectancy (WHO) — Kaggle](https://www.kaggle.com/datasets/kumarajarshi/life-expectancy-who)

## Methods
- Exploratory data analysis and correlation analysis
- Multiple linear regression and AIC-based feature selection
- Ridge regression
- Multicollinearity analysis and regression diagnostics
- Box–Cox transformation

## Tools
R · dplyr · ggplot2 · lmtest · ridge · MASS

## Project Files
- `analysis.R` — Statistical analysis and regression modelling
- `LifeExpectancyAnalysis.pdf` — Project presentation and visualisations
